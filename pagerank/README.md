# 迭代排序库（PageRank 风格，纯标准库 Python 3）

## 文件
- `pagerank.py` —— 库：迭代法 `iterative_rank`、直接解 `direct_rank`、守恒断言 `assert_conservation`
- `test_pagerank.py` —— 自测：特殊图覆盖、直接解对拍、守恒断言、百万边耗时

## 运行
```bash
cd pagerank
python3 test_pagerank.py
```

## 模型与公式
阻尼因子 `d` 可配置（默认 0.85），`tol`、`max_iter` 可配置：

```
r_new[i] = (1-d)/N + d * ( Σ_{j→i} r[j]/outdeg(j) + dangling_mass/N )
```

**悬挂节点规则**：无出边节点的分数均匀分配给全部 N 个节点
（等价于补 N 条指向所有节点的出边）。每轮每个节点的分数都被完整转移，
加上总和为 `(1-d)` 的均匀传送项，因此 `sum(r) = 1` 逐轮守恒，
`assert_conservation` 对此做显式断言。

**收敛判据**：两轮迭代分数向量的最大变化量（L∞）
`residual = max_i |r_new[i] - r_old[i]| < tol` 时收敛，`max_iter` 兜底；
返回收敛轮数与最终残差。

**直接解**：解 `(I - dL)r = (1-d)/N · 1`（L 为悬挂列补 1/N 的列随机矩阵），
部分主元高斯消元，仅用于小规模对拍。

## 自测结果（Python 3.12.3）

### 对拍数据（迭代 vs 直接解，容差 1e-8）
| 图 | max diff | 收敛轮数 | 最终残差 | 分数和 |
|---|---|---|---|---|
| 空图 | — | 0 | 0 | — |
| 单点 | 0 | 1 | 0 | 1.0 |
| 完全图 K6 | 1.1e-16 | 1 | 0 | 1.0 |
| 悬挂节点 | 3.0e-13 | 67 | 7.5e-13 | 1.0 |
| 多不连通分量 | 2.6e-14 | 15 | 1.6e-13 | 1.0 |
| 随机图 d=0.5 | 8.1e-13 | 32 | 9.8e-13 | 1.0 |
| 随机图 d=0.85 | 2.7e-13 | 61 | 4.8e-13 | 1.0 |
| 随机图 d=0.99 | 4.3e-13 | 161 | 9.2e-13 | 1.0 |

另验证：`max_iter=5` 时正确触发上限（未收敛，残差 5.5e-3）；
守恒断言能检出 sum≠1 的错误向量。

### 百万边耗时（N=100,000，M=1,000,000，d=0.85，tol=1e-10）

| run | 总耗时 | 每轮 |
|---|---|---|
| 1 | 1.50s | 125ms |
| 2 | 1.39s | 116ms |
| 3 | 1.56s | 130ms |
