# 相似度与距离度量库

纯 Python 3 标准库实现，无第三方依赖。不同场景对「相似」的定义不同，
本库为每种度量写明返回范围与语义，并对数学性质、数值稳定性给出可断言的保证。

## 文件

| 文件 | 说明 |
|---|---|
| `similarity.py` | 库源码 |
| `test_similarity.py` | 性质断言测试 + 与朴素实现对拍 |
| `benchmark.py` | 百万次计算性能基准 |

## 运行命令

```bash
cd similarity_lib
python3 test_similarity.py   # 17 项测试：性质断言 + 对拍 + 边界
python3 benchmark.py         # 各度量 1,000,000 次计算耗时
```

## 度量一览：返回范围与语义

| 函数 | 范围 | 语义 | 是否严格度量 |
|---|---|---|---|
| `cosine_similarity(a, b)` | [-1, 1] | 1=同向，0=正交，-1=反向；只看方向不看模长 | 否（相似度） |
| `cosine_distance(a, b)` | [0, 2] | 1 - 余弦相似度；**不满足三角不等式**，仅用于排序 | 否 |
| `euclidean_distance(a, b)` | [0, +∞) | L2 距离，对模长敏感 | **是** |
| `manhattan_distance(a, b)` | [0, +∞) | L1 距离，对离群分量不如 L2 敏感 | **是** |
| `jaccard_similarity(a, b)` | [0, 1] | \|A∩B\| / \|A∪B\|，集合型相似度 | 否（相似度） |
| `jaccard_distance(a, b)` | [0, 1] | 1 - Jaccard 相似度 | **是** |

严格度量满足：对称性、非负性、同一对象距离为零、三角不等式。
以上性质均在 `test_similarity.py` 中以随机数据（稠密 + 九成以上为零的稀疏）
做了断言。

## 输入形式

- 向量：等长序列（稠密），或 `dict`（稀疏，缺失键按 0 处理，按键集并对齐）；
  两者可混用。稠密序列长度不一致抛 `ValueError`。
- 集合：任意可迭代对象，内部转 `set`。

## 边界与数值稳定性说明

- **零向量**：余弦相似度定义为 `0.0`（余弦距离 `1.0`），确定结果，不报错；
  欧氏/曼哈顿距离为零向量时正常返回。
- **空集合**：`jaccard_similarity(∅, ∅) = 1.0`（约定空集与自身最相似），
  距离相应为 `0.0`。
- **极小范数**（如 1e-300）：范数用 `math.hypot` 计算，缩放安全；
  余弦走「先归一化再点积」路径，避免范数乘积下溢为 0 导致除零。
- **量纲差异极大**（如 1e150 与 1e-150）：余弦仍给出正确方向结果；
  距离类给出有限确定值。
- **真溢出**（如分量差超出 float64 上限）：抛 `OverflowError`，
  **绝不返回 inf/nan**；所有接口保证结果非有限时明确报错。
- 求和统一用 `math.fsum`（精确舍入），避免长向量累加的灾难性抵消。

## 对拍与性能数据

测试与朴素实现（直接 `sum`/`sqrt` 写法）对拍：稠密 32 维、稀疏 1000 维
（95% 为零，且验证 dict 稀疏表示与稠密表示结果一致）、随机集合，
各 300 组随机样本，结果在 1e-8~1e-10 精度内一致。

性能（Python 3.12.3，每度量 1,000,000 次调用，数据池循环复用）：

| 场景 | 度量 | 单次耗时 |
|---|---|---|
| 稠密 64 维 | cosine | 9.7 µs |
| 稠密 64 维 | euclidean | 5.2 µs |
| 稠密 64 维 | manhattan | 4.3 µs |
| 稀疏 1000 维（95% 零） | cosine | 20.4 µs |
| 稀疏 1000 维（95% 零） | euclidean | 13.7 µs |
| 稀疏 1000 维（95% 零） | manhattan | 13.1 µs |
| 集合（15 元素） | jaccard sim/dist | 1.2 µs |

注：基准用 2000 条数据循环跑满百万次；若预生成百万条数据，
数 GB 内存占用会导致换页，测出的将是内存而非计算耗时。
