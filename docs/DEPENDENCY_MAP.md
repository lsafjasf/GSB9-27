# 依赖映射（文件改动 → 检查项）

映射不是写死的表，而是由每个检查项的**声明式依赖**推导（见
`inccheck/checks.py` 的 `default_checks()`）。本文件是推导结果与规则说明。

## 检查项 → 依赖声明

| 检查项 | 名称 | 目标文件（path_patterns） | 消费的配置（config_paths） | 依赖图 | 树敏感（watch） |
|---|---|---|---|---|---|
| C001 | py-syntax | `src/**/*.py` | `checks.conf` | 否 | 否 |
| C002 | py-imports | `src/**/*.py` | `checks.conf` | **是**（反向依赖扇出） | 否 |
| C003 | line-length | `src/**/*.py` | `checks.conf`（`line-length`） | 否 | 否 |
| C004 | manifest | 全局（无文件目标） | `MANIFEST.txt` | 否 | **是**（`src/**/*.py` 的增删） |
| C005 | doc-heading | `docs/**/*.md` | `checks.conf` | 否 | 否 |

## 文件改动 → 受影响的检查目标

| 改动路径 | 状态 | 推断出的检查目标 |
|---|---|---|
| `src/x.py` | M | C001/C002/C003(x)；若 x 被导入，C002 沿**反向依赖闭包**扇出到所有（传递）导入者 |
| `src/x.py` | A | C001/C002/C003(x) + C004（树敏感） |
| `src/x.py` | D | C002 扇出到 x 的所有导入者 + C004；x 自身的目标从宇宙中移除 |
| `checks.conf` | M | 所有声明消费它的检查（当前 = 全部 5 项）的全部目标 |
| `MANIFEST.txt` | M | 仅 C004 |
| `docs/*.md` | M/A/D | C005(该文件) |
| 其他任意路径 | * | **无法推断 → 回退全量（F2）** |

反向依赖来自 `inccheck/depgraph.py`：用 `ast` 解析全部 `src/**/*.py`
的 import（含 `from x import y` 展开到子模块、相对导入），按被导入名
（含包前缀）建反向索引，改动模块时取传递闭包。删除文件时，被删模块名
以 `extra_modules` 注入，保证指向已删除模块的边仍然可解析。

## 缓存键（决定"选中后是否真的重跑"）

静态推断给出上界（selected），缓存键做精确裁剪（ran ≤ selected）。
每个 (检查, 目标) 的键 = SHA256( 引擎版本, 检查ID, 所有 config_paths 内容,
目标文件内容, [C002: 每条 import 边的解析结果 + 被导入文件哈希],
[C004: src 下 .py 文件清单] )。键不变 ⇒ 结果必然不变 ⇒ 直接复用基线结果。

## 回退全量的触发条件

| 代码 | 条件 | 理由 |
|---|---|---|
| F1 | 无基线缓存（冷启动） | 没有可复用的结果 |
| F2 | 改动文件不被任何检查项/配置认领 | 影响面未知，无法安全裁剪 |
| F3 | 任一项目 .py 解析失败（语法错误） | 依赖图不可信，扇出可能漏 |
| F4 | 改动路径越出仓库根（`../`、绝对路径） | 输入非法 |
| F5 | 未知变更状态（非 A/M/D） | 输入非法 |

回退 = 退化为全量执行（结果与全量逐字节一致，只是慢），绝不猜测。
对应测试：`tests/test_plan.py::TestUninferable`、`tests/test_equivalence.py`。
