# angle_utils — 角度归一化与二维坐标旋转

纯 Python 3 标准库实现，解决"角度累积到多圈甚至上万度后，直接取模在负数与
大数上出错"的问题。

## 文件

- `angle_utils.py` — 库：归一化 / 弧度互转 / 二维旋转 / 误差估计
- `test_angle_utils.py` — 幂等、边界、精度测试（unittest，20 个用例）
- `precision_report.py` — 打印完整误差数据表

## 运行命令

```bash
cd angle_lib
python3 -m unittest test_angle_utils -v   # 跑全部测试
python3 precision_report.py               # 打印误差数据表
```

## 约定（零度与负角）

- 单位为**度**，**逆时针为正**（数学惯例，y 轴向上）；负角 = 顺时针。
- 归一化区间为**左闭右开** `[start, start + period)`：正好落在上边界的值
  回卷到 `start`（`360 -> 0`，`normalize_180(180) -> -180`）。
- 结果中的零**恒为 +0.0**（`-0.0` 被规范化），可直接用 `==` 比较。
- `rotate2d` 在角度为 0 时严格返回原坐标（cos=1、sin=0 精确）。
- 非有限输入（inf/nan）抛 `ValueError`。

## 实现要点

- 用 `math.fmod`（精确运算）而非 `%`，并显式处理：负余数平移、
  平移后舍入撞上 `period`、加回 `start` 后舍入撞上开边界、`-0.0`。
- **幂等性**：`normalize(normalize(x)) == normalize(x)`，由测试覆盖
  （固定边界值 ±ulp、4 万个随机值、±50 个整圈附近的对抗值、多种 start）。
- `rotate2d` **先归一化再转弧度**，避免对巨大角度直接依赖 libm 的参数约减。

## 误差数据（python3 precision_report.py 实测）

归一化 `10^n` 度（解析真值 = `10^n mod 360`，n≥3 时恒为 280）：

| n | ulp(10^n) 度 | 归一化结果 | 绝对误差 |
|---|---|---|---|
| 6（百万度） | 1.2e-10 | 280.0 | 0 |
| 15 | 1.3e-01 | 280.0 | 0 |
| 18 | 1.3e+02 | 280.0 | 0 |
| 22 | 2.1e+06 | 280.0 | 0 |
| 23 | 1.7e+07 | 32.0 | **248°** |
| 24 | 1.3e+08 | 144.0 | **136°** |

要点：`10^n` 在 n≤22 时能被 double 精确表示（10^n = 5^n·2^n，尾数够用），
`fmod` 又精确，所以误差恒为 0；n=23 起输入本身就有 ~10^7 度的表示误差，
归一化结果完全失真。

旋转 `(1,0)` 转 `30° + 360°·10^k`（对比 60 位 Decimal 参考值）：

| k | 角度（度） | ulp（度） | \|Δcos\| / \|Δsin\| |
|---|---|---|---|
| 0 | 390 | 5.7e-14 | 6.1e-17 / 5.6e-17 |
| 6 | 3.6e8 | 6.0e-08 | 6.1e-17 / 5.6e-17 |
| 13 | 3.6e15 | 5.0e-01 | 6.1e-17 / 5.6e-17 |

要点：只要角度本身能被 double 精确表示（此处 ≤2^53 的整数），
"先归一化再旋转"的误差始终停留在机器精度 ~1e-16。真正的风险不是运算，
而是**输入角度的表示误差** `ulp(angle)`。

## 何时应放弃 float64 归一化、改用高精度表示

经验法则：归一化结果的固有不确定度 ≈ `ulp(angle) ≈ |angle| · 2.2e-16`。
用 `normalization_error_bound(angle)` 查询。

| 所需精度 | float64 安全的最大角度 |
|---|---|
| 1e-3° | ~4.5e12° |
| 1e-9° | ~4.5e6° |
| 1e-15° | ~4.5° |

- 当 `ulp(angle)` 超过所需精度时：改用**整数圈数 + 小数偏移**分离表示，
  或用 `decimal.Decimal` / `fractions.Fraction` 保存角度。
- 当 `|angle| ≥ 360·2^52 ≈ 1.6e18°` 时，ulp 已超过一整圈，归一化毫无意义。
- 工程上最好的做法是**每次累加后立即取模**，让角度永远不累积到大数。
