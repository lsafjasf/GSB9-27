# 撤销列表（Revocation List）

纯标准库 Python 3 实现，时间可注入，持久化 + 有界 + 三态判定。

## 运行

```bash
cd revocation
python3 -m unittest -v     # 17 个自测（含重启一致性、边界用例）
python3 bench.py           # 100 万次查询基准
```

## 设计要点

- **记录模型**：`jti -> 令牌自然过期时间 exp`。记录只需活到令牌自然失效，
  这就是存储的上界；`purge()` 删除 `exp <= now` 的记录。
- **三态判定** `check(jti, exp)`：
  - `REVOKED`：存在未过期的撤销记录；
  - `NOT_REVOKED`：令牌仍在自然有效期内且无记录；
  - `UNKNOWN`：令牌已自然过期且无记录（记录可能已被清理，无法判定）。
    **策略**：过期令牌本来就应拒绝，UNKNOWN 一律按拒绝处理即安全。
- **持久化**：JSON 快照，tmp 文件 + `os.replace` 原子写入 + fsync，
  崩溃不会写坏旧文件；重启后 `load()` 恢复，判定完全一致（有测试）。
- **时间回拨**：`purge` 只删 `exp <= now` 的记录，回拨只会少删不会错删；
  测试覆盖回拨后记录仍存活、判定不变。
- **内存释放**：清理时重建 dict 而非逐个 `del`（CPython dict 删除不缩容）。

## 实测数据（Python 3.12.3, 本机）

- 内存：10,001 条记录约 936,579 B → purge 后 1 条记录 257 B。
- 耗时：1,000,000 次 `check` 共 0.505 s，约 0.505 µs/次，≈ 198 万 QPS
  （50% 命中撤销、50% 未撤销）。
