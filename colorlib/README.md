# colorlib — 颜色空间转换库（Python 3，仅标准库）

## 运行命令

```bash
cd colorlib
python3 selftest.py        # 单元测试 + 往返误差评估 + 百万像素性能基准
python3 -c "import colorlib; print(colorlib.srgb8_to_linear((128,128,128)))"
```

## 实现的转换

| 链路 | 说明 |
|---|---|
| sRGB 8bit ↔ 线性 RGB float [0,1] | 含 gamma 校正（核心链路） |
| sRGB 8bit ↔ HSV (h:[0,360), s/v:[0,1]) | HSV 定义在 gamma 编码值上，与常见图形软件一致 |
| sRGB 8bit ↔ CIE XYZ (D65/2°) | 经线性 RGB 中转 |

## 常数与取整规则

- gamma 校正遵循 IEC 61966-2-1 分段函数：线性段斜率 12.92，分段点
  0.0031308（线性侧）/ 0.04045（sRGB 侧），幂指数 2.4，增益 a=1.055。
- XYZ 矩阵为 IEC 61966-2-1 的 D65/2° 标准矩阵（4 位小数）。
- 取整：float→8bit 一律 round-half-up，即 `floor(x*255 + 0.5)`；
  不用 Python 内置 `round`（银行家舍入），保证结果跨平台可复现。
- 解码方向（8bit→线性）使用 256 项查找表，无精度损失且更快。

## 越界策略

- `mode="clamp"`（默认）：负值裁到 0，超上限裁到上限（XYZ 上限 1.5，
  因 D65 白点 Z≈1.089）。
- `mode="strict"`：任何越界抛 `ValueError`。
- NaN、非数值、通道数错误在两种模式下都抛 `ValueError`，绝不静默产生错乱像素。

## 往返误差（110 万样本：100 万随机 + 10 万暗部密集，8bit 灰阶单位）

| 链路 | 各通道最大误差 | 各通道平均误差 |
|---|---|---|
| sRGB8→linear→sRGB8 | 0 | 0 |
| sRGB8→HSV→sRGB8 | 0 | 0 |
| sRGB8→XYZ→sRGB8 | 0 | 0 |

误差来源分析：

- 中间值用 float64 表示时，精度（约 1e-16）远高于 8bit 量化步长，
  往返误差被 round-half-up 完全吸收，故实测为 0（灰度 256 级已穷举验证）。
- 真正的误差来源是**中间存储位深**。实测线性中间值量化后的往返误差：

  | 线性中间值位深 | 最大误差 | 平均误差 |
  |---|---|---|
  | 16 bit | 0 | 0.000 |
  | 12 bit | 0 | 0.000 |
  | 10 bit | 2 | 0.074 |
  | 8 bit  | 6 | 0.495 |

- 结论 / 可接受范围：中间值 ≥12 bit 时往返无损；10 bit 时误差 ≤2 灰阶，
  集中在暗部（线性量化在暗部步长最粗），一般可接受；8 bit 线性存储
  暗部压死明显（最大 6 灰阶），应避免。这正是"暗部细节丢失"的根因：
  线性空间暗部量化分辨率不足，而非 gamma 函数本身。

## 边界用例集（selftest.py，9 组测试全过）

- 全黑 (0,0,0)、全白 (255,255,255)：三链路精确往返，白点 Y=1.0。
- 极暗 (1..3)：验证线性段斜率 12.92，往返无损。
- 极亮 (253..255 组合)：往返无损。
- 单通道：纯红/绿/蓝、单通道值为 1 的极暗色、半亮单色。
- 越界：-5、300、1.5、-0.2 等，clamp 模式裁剪、strict 模式拒绝。
- 非法输入：NaN、字符串、布尔、通道数不足，一律 ValueError。
- 全部 256 级灰度穷举往返零误差。

## 性能（CPython 3.12.3，100 万像素，单线程纯 Python）

| 操作 | 耗时 | 吞吐 |
|---|---|---|
| sRGB8 → linear | ~0.55–0.97 s | ~1.0–1.9 Mpx/s |
| linear → sRGB8 | ~0.72–0.87 s | ~1.2–1.4 Mpx/s |
| sRGB8 → HSV | ~0.71–0.90 s | ~1.1–1.4 Mpx/s |
| HSV → sRGB8 | ~0.42 s | ~2.4 Mpx/s |
| sRGB8 → XYZ | ~0.67–0.89 s | ~1.1–1.5 Mpx/s |
| XYZ → sRGB8 | ~1.23–1.49 s | ~0.7–0.8 Mpx/s |
| 往返 linear / HSV | ~1.2–1.6 s | ~0.6–0.8 Mpx/s |

（区间为本机多次运行波动；生产环境如需更高吞吐，可用相同 LUT 思路
在 C/NumPy 层批量查表，接口语义不变。）
