# 活跃变量分析（Liveness Analysis）

纯 Python 3 标准库实现。基于控制流图的后向数据流分析，迭代到不动点，
输出每个基本块的入口活跃集合 `live_in` 与出口活跃集合 `live_out`，
供寄存器分配与死代码消除使用。

## 文件

- `liveness.py` — 库：`Instr` / `BasicBlock` 模型，两个求解器
  - `solve_liveness_worklist`：worklist 混沌迭代（高效）
  - `solve_liveness_naive`：固定块序逐点迭代（对拍基准）
- `cfggen.py` — CFG 生成器：随机图、长链、深层嵌套循环
- `diff_test.py` — 对拍脚本（612 例）
- `test_edge_cases.py` — 14 个边界用例单测
- `bench.py` — 上千基本块的收敛轮数与耗时

## 数据流方程

```
live_out[B] = ∪  live_in[S]      （S 取遍 B 的正常后继 + 异常后继）
live_in[B]  = use[B] ∪ (live_out[B] − def[B])
```

`use[B]`/`def[B]` 由块内指令前向扫描得到（向上暴露使用 / 块内定值）。
异常跳转边按块级保守处理：可能抛异常的块，其 `live_out` 并入异常处理器
入口的活跃集合——这是声音的（sound）近似，宁可多报活跃也不少报。

## 迭代顺序与收敛依据

**Worklist 求解器**：初始 worklist 按"逆 CFG 的逆后序"（RPO of the
transpose graph）排序——后向分析的信息沿边反向流动，让后继先于前驱被
计算，一轮即可把信息传播到位。之后采用混沌迭代：块 B 的集合变化时，
仅把 B 的前驱重新入队。从所有出口块做逆图 DFS 得到该顺序；从入口不可达
或到不了出口的块也会被追加进初始 worklist，因此**不可达块同样被分析**。

**朴素求解器**：按固定块序整轮扫描，整轮无任何变化才停机。

**收敛依据**：格 `(2^Vars, ⊆)` 高度有限（≤ |Vars|）；传递函数单调；
初值为 ∅ 且每次更新只增不减，构成有限上升链，故两者必在有限步内终止。
由混沌迭代（chaotic iteration）定理，任意公平的迭代序都收敛到同一
**最小不动点**——这就是两个实现结果必然一致、可以对拍的理论保证。
活跃变量分析是 may 分析且传递函数可分配，故 MFP = MOP。

**顺序影响实测**（见下表）：对后向分析，块 id 升序是坏序（链 5000 块需
9 轮），降序是好序（2 轮）；worklist 与好序无关，恒为约 n 次求值。

## 收敛轮数与耗时（Python 3，单次运行，wall-clock）

| 图结构 | 块数 | 边数 | naive 轮数 | naive 求值/耗时 | worklist 求值/耗时 |
|---|---|---|---|---|---|
| 链（仅前向边），naive 坏序(升序) | 5000 | 4999 | 9 | 45000 / 14.9 ms | 5000 / 11.8 ms |
| 嵌套循环 d50×b40（含异常回路） | 2002 | 2101 | 24 | 48048 / 26.7 ms | 2342 / 4.5 ms |
| 嵌套循环 d100×b20（无异常边） | 2001 | 2100 | 19 | 38019 / 21.0 ms | 2452 / 4.0 ms |
| 嵌套循环 d50×b40，naive 好序(降序) | 2002 | 2101 | 3 | 6006 / 5.1 ms | 2342 / 3.2 ms |
| 链，naive 好序(降序) | 5000 | 4999 | 2 | 10000 / 5.2 ms | 5000 / 10.5 ms |
| 随机图（循环+异常边+不可达岛） | 2000 | 11874 | 7 | 14000 / 32.7 ms | 4765 / 17.4 ms |
| 随机图，高密度回边 | 4000 | 38875 | 9 | 36000 / 151.9 ms | 9385 / 59.4 ms |

所有规模下两求解器结果逐块完全一致。嵌套循环越深，naive 轮数随深度
线性增长（信息要逐层穿回边），worklist 求值次数始终接近块数。

## 边界用例（test_edge_cases.py，14 例）

空图、单块（无指令/纯使用/先定后杀/向上暴露使用）、仅前向边的链与菱形
汇合、自环、两块循环、不可达块（仍被分析）、异常边（含仅有异常边的块）、
死定值不活跃、三层嵌套循环带异常回路（两求解器一致 + 回路活跃性断言）。

## 运行命令

```sh
cd liveness
python3 test_edge_cases.py   # 边界用例单测（14 例）
python3 diff_test.py         # 对拍：612 个随机/结构化 CFG，0 不一致
python3 bench.py             # 收敛轮数与耗时（最大 5000 块）
```
