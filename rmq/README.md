# 静态数组区间最值查询（Sparse Table / RMQ）

纯 Python 3 标准库实现，预处理一次后 O(1) 回答任意闭区间 `[l, r]` 的最值与最值下标。

## 文件

- `rmq.py` — 库：`SparseTable(arr)`，方法 `range_min(l, r)` / `range_max(l, r)` / `min_index(l, r)` / `max_index(l, r)`
- `test_rmq.py` — 自测：边界情形 + 与暴力扫描随机对拍
- `bench.py` — 基准：预处理耗时、百万次查询耗时、内存占用

## 运行

```bash
python3 test_rmq.py            # 自测 + 对拍
python3 bench.py               # 默认 n=1,000,000，查询 1,000,000 次
python3 bench.py 100000 500000 # 自定义规模
```

## 复杂度

| 项目 | 复杂度 |
|---|---|
| 预处理时间 | O(n log n) |
| 预处理空间 | O(n log n)，约 `2·n·(log2 n + 1)` 个槽位（min/max 两张表） |
| 单次查询 | O(1)：取 `k = floor(log2(r-l+1))`，合并两个重叠的长度 `2^k` 区间 |
| 数组修改 | 不支持（静态结构，修改需重建） |

## 平局规则（确定性）

区间内出现多个相同最值时，**返回最小的下标**（最左出现位置）。
实现上合并两段时仅在严格更优（`<` / `>`）时才取右段，相等保留左段下标。

## 实测数据（Python 3.12，n = 1,000,000，查询 1,000,000 次）

- 预处理耗时：约 1.4 s
- 结构内存：约 377 MiB（约 395 字节/元素；含 min/max 两张表）
- 单次查询：约 0.4 µs（百万次 min + 百万次 max 各约 0.4 s）
- 进程峰值内存（含原数组与查询列表）：约 538 MiB

## 自测覆盖

- 单元素数组、全相同元素、严格递增/递减、重复最值交错
- 区间长度 1、区间覆盖全数组、平局取最左下标
- 空数组与非法区间抛错
- 随机对拍：300 轮随机数组（小值域制造大量平局）× 每轮 20 个随机区间，
  min/max 的值与下标与暴力扫描逐次一致
